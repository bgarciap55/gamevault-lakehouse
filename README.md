# gamevault-lakehouse

Lakehouse de videojuegos en Azure Databricks (medallion con PySpark, Unity Catalog, Data Factory, Delta Sharing y CI/CD con Asset Bundles).

Todo el proyecto está en [`databricks-app/`](databricks-app/); empieza por su [README](databricks-app/README.md). Los workflows de GitHub Actions están en `.github/workflows/` porque GitHub solo los lee desde la raíz del repo.
